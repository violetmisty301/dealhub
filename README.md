# DealHub Web v1.0 DEMO
GitHub Pages 작동 확인용 정적 웹앱입니다.

## 배포
1. 이 ZIP의 압축을 풉니다.
2. `index.html`, `style.css`, `app.js`, `README.md`를 GitHub `dealhub` 저장소의 최상위(root)에 업로드합니다.
3. Commit changes 합니다.
4. Settings > Pages > Build and deployment > Source: Deploy from a branch
5. Branch: main, Folder: /(root), Save
6. 1~5분 후 `https://<GitHub아이디>.github.io/dealhub/` 접속

현재 데이터는 DEMO입니다. 다음 단계에서 자동 수집을 연결합니다.
